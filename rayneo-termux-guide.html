Field diagnostic · stage two

Reading the IMU

Claim the glasses' HID interface from Termux and dump what the sensor is sending. No root, no Android Studio.

01

Install Termux

Not from the Play Store. That build is abandoned and its USB support is broken. Get it from F-Droid or the Termux GitHub releases page.

Install Termux and Termux:API from the same source — mixing sources breaks the signature check and the two apps won't talk to each other.

02

Install the packages

Open Termux and run these one at a time:

pkg update
pkg install python libusb termux-api

Takes a couple of minutes on 4G. If pkg update stalls, run termux-change-repo and pick a different mirror.

03

Get the script across

Download rayneo_dump.py to your phone, then:

termux-setup-storage
cp ~/storage/downloads/rayneo_dump.py ~/
cd ~
ls

Grant the storage permission when Android asks. You should see the filename listed.

04

Find the glasses

Plug the glasses in, then:

termux-usb -l

You should get back a path like:

[
  "/dev/bus/usb/001/002"
]
Empty list? Unplug, replug, and check the glasses are powered up and showing a picture. If it stays empty, Termux can't see them and this route is closed.
05

First read

Use your own path from step 4:

termux-usb -r -e "python rayneo_dump.py" \
  /dev/bus/usb/001/002

Android will pop a permission dialog. Accept it. The script claims interface 0 and listens for 15 seconds — move your head around the whole time.

What good looks like: rows of hex where some bytes sit in square brackets. Brackets mean that byte changed since the last frame. Those are your gyro axes.
06

If nothing arrives

Frames read = 0 means the IMU is idle until told to start. Try the guessed wake-up patterns:

termux-usb -r -e "python rayneo_dump.py --probe --seconds 20" \
  /dev/bus/usb/001/002

These are generic patterns from similar vendor HID glasses, not RayNeo's actual command. Low odds, but it costs nothing to fire them.

Still silent? Then the real command has to come from watching the Windows SDK do it — USBPcap and Wireshark on a PC with the glasses attached. That's a bigger job, and worth deciding on before you start.

07

Other switches

  • --all — print every frame, not just changed ones
  • --seconds 30 — listen longer
  • --send 0201 — fire a specific hex command first
  • --ep 0x82 — try a different input endpoint

Put switches inside the quotes, after the script name.

08

Send me the output

Long-press in Termux, choose More → Select text, or just screenshot it. Paste back roughly twenty frames plus the summary block and we'll map which bytes are yaw, pitch and roll.

Even with the IMU fully decoded, this gets you a head-tracked floating screen on Android. It does not get you head-look inside a game — no Android title accepts an orientation input stream. That part only exists on Windows.
