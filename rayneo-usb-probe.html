RayNeo USB Probe

Checks whether an Android browser can reach the IMU interface inside RayNeo Air glasses. Answers one question: is there a door in?

01

Browser support

Runs on load. Needs Chrome or Edge on Android over https or a local file. Firefox and Safari have no WebUSB.

02

Connect glasses

Plug the glasses into the phone, then tap below and pick the RayNeo entry from the chooser. If nothing is listed, the video path is working but the data path is hidden from the browser.

03

Claim interfaces

Tries to take control of each interface in turn. Protected classes such as HID are usually refused — that refusal is itself a result worth recording.

04

Listen for motion

Reads any claimed input endpoint for five seconds. Move your head while it runs. Changing bytes mean live IMU data.

05

Send me the results

If the chooser is empty: the glasses expose no browser-accessible interface, and no Android app can read the gyro either. That is a real answer, not a failure of this tool.
